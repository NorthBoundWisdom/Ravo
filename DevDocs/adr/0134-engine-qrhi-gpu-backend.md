# ADR-0134: Engine QRhi GPU backend

- Status: Accepted
- Date: 2026-09-03
- Extends: [ADR-0133](0133-engine-gpu-preview-adapter.md)
- Relates to: [MIGRATION.md](../MIGRATION.md) GPU row

## Context

ADR-0133 put GPU in an Engine-owned adapter with no silent CPU fallback.
The first host implementation was Apple Metal. A second D3D or Vulkan copy of
the same kernels would split ownership. Qt 6.11 already ships QRhi, which
selects Metal, D3D, or Vulkan at run time from one compute shader baked by
`qsb`.

## Decision

- `GpuAdapter` remains the Engine-owned C++ interface. Public `engine.h` does
  not mention QRhi, QImage, or a graphics API.
- One private QRhi backend owns device, buffers, dispatch, and readback.
  Compute shaders live as GLSL `.comp` sources and are baked to `.qsb` at
  build time. Generated bytes are compiled into the engine; they are not
  hand-edited.
- `ravo_engine` may link `Qt6::Gui` and `Qt6::GuiPrivate` for this adapter.
  GuiPrivate is only the versioned `rhi/qrhi.h` include path; public `engine.h`
  stays free of QRhi and QImage. Recipe, Catalog, CLI, and QML still do not
  hold device objects. QML/Qt Quick RHI is not a second image pipeline. Qt
  Widgets stay forbidden. The Engine is tied to the Qt 6.11 QRhi layout.
- Host order is Metal, D3D12, D3D11, then Vulkan. OpenGL is not admitted
  until a dated decision covers `QGuiApplication` / offscreen surfaces. Missing
  compute or buffer readback is `gpu_unavailable`.
- CPU remains the RMSE gold and the export path. Preview interleaves GPU
  Exposure/Sigmoid with remaining CPU RGB ops when a compute backend exists.

## Consequences

Apple, Windows, and Linux share one kernel. CLI and tests may create a
process-lifetime `QCoreApplication` if none exists so Qt can load the RHI
backend. Native Metal sources are removed.

## Rejected alternatives

- Hand-written Metal, D3D, and Vulkan adapters.
- QML or `QRhiWidget` as the photo pipeline.
- Runtime `QShaderBaker` in production (build-time `qsb` owns the artifact).
- Silent CPU copy when QRhi init fails.
